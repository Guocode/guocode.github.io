02 / 成绩对比

8 个 seed × 16 回合平均（训练上限 60 秒，无尽模式——成绩 = 失败前累计距离）。「失败率」指摔倒 / 冲出路面的比例。

策略 机器人距离 失败率 汽车里程 失败率

启发式规则是我手写的：机器人「倒立摆 PD 平衡——倾角与角速度加权超阈值就反向打力矩」， 汽车「按横向偏移 + 航向角 + 前瞻曲率反打方向，事件期间提前预修正」。 诚实结论：加入随机起伏地形后，平衡关 AI 学会了贴合地形节奏的主动平衡——8 个 seed 全部跑满 60 s 时限（274.4 m，与启发式持平且零摔倒）； 公路关事件机制 v3（打滑改为角载荷触发 + 冲量衰减 + 冷却期）后整体更「讲道理」： 启发式从 336.9 m 提升到 503.8 m，AI 500.4 m 与其同档（多 seed 平均相差 <1%）—— 当随机惩罚变成可学习的行为后果，简单的手写规则也能逼近上限，这本身就是个有意思的观察。

05 / 训练过程

多任务 PPO，两个环境各 32 个并行实例，共 500 次更新（纯 CPU）。 平衡与车道保持这类连续微调靠随机探索很难起步，所以先用启发式做行为克隆预热，再交给 PPO 微调。

汽车曲线波动很大，这是设计使然：打滑 / 爆胎是随机事件，同样的策略可能跑 100 米也可能跑 800 米。 保存的是综合得分最高的 checkpoint（机器人距离 / 150 + 汽车里程 / 400）。

06 / 模型架构

小到可以直接在 JS 里手写前向：不需要 wasm 运行时，页面加载完就能玩。

为什么用 MoE

而不是两个独立模型
  • 两个游戏状态语义完全不同（倒立摆姿态 vs 车道几何），共享 trunk 学通用表征，专家负责分化
  • 路由权重可直接可视化，模型「在想什么」不再是黑盒
  • 加新游戏时只需扩专家，不必重训整个网络

训练要点

踩过的坑
  • 软/硬两档力矩（转向）比单档收敛更快——细调与救场由路由自动选择
  • 两个任务奖励尺度差数倍 → advantage 按任务分别归一化
  • 加了 Switch Transformer 的负载均衡损失，避免路由坍缩到单个专家

为什么不用 ONNX Runtime

工程取舍
  • 模型仅 22K 参数，手写前向比拉 10 MB 的 wasm 运行时更快也更稳
  • 仓库内同时提供 train/export_onnx.py，一条命令即可导出标准 ONNX（需 pip install onnx），链路可迁到任何推理框架
  • JS 前向与 PyTorch 输出误差 1.9e-6；物理引擎两端用启发式策略做统计一致性校验
  • 页面因此零依赖、离线可玩、首屏即开

07 / 两个游戏怎么设计的

两个环境都是自己写的轻量物理，Python（训练）与 JavaScript（浏览器）各实现一份，共用同一套常量和积分公式。

GAME 00 · 独轮平衡机器人

倒立摆 + 驱动轮 · 无尽平衡挑战
  • 无腿设计：躯干直接立在驱动轮上，是一个经典的倒立摆——不控制就必摔
  • 自动前进：轮子按预设速度一直向前滚（2.2 m/s 起步，随时间爬升到 6.5 m/s），前进本身带步频抖动
  • 平衡噪声：OU 随机过程持续晃动身体，速度越快噪声越大；另有随机颠簸事件（坑洼）产生短促冲击
  • 随机起伏地形：地面由三个正弦叠加的伪随机函数生成（幅度随里程渐入，两端逐位一致）——过凸顶短暂「失重」、上坡后仰下坡前倾，越到后面越颠
  • 玩家操作：只有 4 档平衡力矩（前倾 / 后倾 × 软 / 硬），把身体稳在直立附近
  • 失败：俯仰超过 52°。距离即分数，永不落幕

GAME 01 · 无限公路

自动巡航 + 角载荷打滑 / 爆胎 hazards
  • 去油门刹车：车速全自动——巡航速度随里程爬升（8 → 26 m/s），玩家只管方向
  • 打滑（行为后果）：转弯角载荷越大越容易触发（猛烈过弯才会甩尾），甩尾方向沿当前转向方向，推力随时间衰减，转向力度剩 45%——少打猛方向就能少打滑
  • 爆胎（路面 hazard）：概率随车速上升，强拽 + 瞬间掉速 20%，事件期间巡航恢复变慢，事件结束后有 2 秒冷却，不会连环倒霉
  • 边界与反馈：路面一路铺到画面底部（白色中线虚线随里程滚动），红白路缘石明确标出碰撞边界，临边一侧红色渐亮警示；事件给出被拽方向箭头，反向打盘即可修正，无全屏闪烁
  • 赛道：曲率是解析函数 κ(s)，无尽生成，两端一致；观测含 4 个前瞻曲率
  • 失败：冲出路面。里程即分数，永不落幕

共享接口

为什么能用一个模型
  • 两个游戏都是 4 个离散动作、14 维观测、60 Hz
  • 观测语义不同但维度一致，靠 2 维任务 one-hot 区分
  • 奖励都以前进距离为主项，尺度可比

调参记录

物理是反复改出来的
  • 平衡噪声初版太弱，机器人扶正一次就永远直立 → 改成 OU 过程 + 随速度放大
  • 颠簸事件只给常值力矩会显得"假" → 改成半正弦包络的短促冲击
  • 打滑时若不削弱转向力度，玩家一把方向就能救回来 → 打滑期间转向执行度降到 45%
  • 事件最初是纯随机"天上掉下来"，玩家觉得被暗算 → v3 改成行为驱动（角载荷触发打滑 / 速度越快越易爆胎）+ 冲量衰减 + 冷却期，路缘红白石 + 临边警示让边界一目了然
