# CityDrive — 城市端到端智驾 AI

在自研城市物理环境中训练一个**端到端**强化学习驾驶模型：输入 6 路 BEV 语义相机 + 导航结构化数据，输出加速度与转向。

## 阶段一 · 物理环境（已上线 ✅）

在线 Demo：`/drv-ai/`（手动 W/A/S/D 驾驶 + AI 专家演示切换）

### 环境构成（train/city.py ↔ assets/js/city.js 双端镜像）

| 要素 | 说明 |
| --- | --- |
| 路网 | 4×4 灯控路口网格，路口间距 90 m，双向两车道右侧行驶（车道中心偏移 1.85 m） |
| 静态 | 车道线（±1.85 m）、路沿（±3.7 m）、人行道（3.7~7.0 m）、建筑街区、行道树 |
| 红绿灯 | 每路口 NS/EW 两相位轮换（各 8 s，末 2 s 黄灯） |
| NPC | 22 车辆（跟车 + 红灯停车线 + 绿灯随机转向禁 U 掉头）、6 骑车人（贴路沿）、12 行人（人行道往返） |
| 本车 | 自行车模型，动作 = (加速度 ∈ [-4.5, 2] m/s², 转向 ∈ [-1,1]×0.42 rad)，20 Hz，V_MAX = 14 m/s |
| 导航 | Dijkstra 最优路径 → 到达终点 +10 自动换新终点（无尽）→ 偏离路线 >10 m 从最近路口重规划 |
| 观测 | 6 路 BEV 语义相机（朝向 [0,60,...,300]°，32×32，44.8 m 见方）+ 导航结构化 8 维 |
| 奖励 | 前进进度 + 到达终点 +10；碰撞 -10 / 冲出路面 -5 / 闯红灯 -2 / 重规划 -0.2 / 舒适项 |

### 专家闭环验证（启发式 PD + 安全速度曲线）

8 回合无尽导航测试：**0 碰撞、6~7 个终点、平均 ~4 m/s**。
已知限制：转弯中航向 45° 边界灯态抖动偶发闯红灯（作为 RL 惩罚信号保留）。

## 阶段二 · 端到端模型（进行中）

- `train/model_drv.py`：6 视角共享 CNN（3→8→12→16, stride2 → 4×4×16=256 → fc64）×6 concat 384 + nav 8 → fc128 → 高斯 actor(加速度, 转向) / critic，~86k 参数
- `train/train_drv.py`：专家 BC 预热 + PPO（GPU：RTX 3060 Laptop / torch cu126）
- `train/export_drv.py` → weights.json → 浏览器手写前向（net.js），零依赖实时推理
- 评估指标：完成率 / 碰撞率 / 闯红灯 / 重规划次数 / 均速
